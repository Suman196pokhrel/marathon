# DSA Marathon

A personal study log covering Python internals and data structures & algorithms, built up toward technical interview readiness.

## Contents

- **[block-1](block-1%20_inner_workings_mental_model)**: How Python works under the hood: assignment, aliasing, mutability, identity, copying, and class creation.
- **[block-2](block-2_scalar_types_and_ordered_sequences)**: Scalar types and ordered sequences: numeric types, bitwise operations, the sequence protocol, strings, lists, tuples, and range.
- **[block-3](block-3_hash_containers_control_flow_comprehensions)**: Hash-based containers and control flow: hashing, dicts, sets, and comprehensions.
- **[block-4](block-4-easy-questions-leetcode)**: Easy LeetCode problems grouped by pattern (two pointers, sliding window, hashing, linked lists, and more). Any remaining theory is learned as problems call for it.
- **[complexities](complexities)**: Practice sets for estimating Big O time complexity by reading code.
- **[data-structs](data-structs)**: Core data structures implemented from scratch in Python: dynamic array, singly linked list, stack, and queue. Its README gives a quick intro to each one, with operations, complexities, and why the next structure was needed.

## Suggested order

1. Blocks 1 to 3 build the Python mental model.
2. `complexities` and `data-structs` cover the theory used in interviews.
3. Block 4 puts it all into practice, one pattern at a time.
