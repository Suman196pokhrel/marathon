# DSA Marathon

A personal study log covering Python internals and data structures & algorithms, built up toward technical interview readiness.

## Contents

- **block-1**: How Python works under the hood: assignment, aliasing, mutability, identity, copying, and class creation.
- **block-2**: Scalar types and ordered sequences: numeric types, bitwise operations, the sequence protocol, strings, lists, tuples, and range.
- **block-3**: Hash-based containers and control flow: hashing, dicts, sets, and comprehensions.
- **block-4**: Easy LeetCode problems grouped by pattern (two pointers, sliding window, hashing, linked lists, and more). Any remaining theory is learned as problems call for it.
- **complexities**: Practice sets for estimating Big O time complexity by reading code.
- **data-structs**: Core data structures implemented from scratch in Python: dynamic array, singly linked list, stack, and queue.
